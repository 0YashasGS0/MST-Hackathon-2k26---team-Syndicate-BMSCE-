# MST Blockchain SDKs

> Source: MST official developer docs (docs.mstblockchain.com), copied 2026-09-29 for team reference. Not our content — check the live docs for updates.

Modular, lightweight development kits for any MST-compatible network, with abstractions for providers, signers and contract interactions.

## Available SDKs
| SDK | Language |
|---|---|
| [@mstblockchain/mst-sdk](https://www.npmjs.com/package/@mstblockchain/mst-sdk) | JavaScript / TypeScript |
| [mst-sdk-python](https://pypi.org/project/mst-sdk-python/) | Python |

## Common features
- Connect to MST Mainnet and Testnet RPC out of the box
- Send transactions and interact with smart contracts
- Query wallet balances, transaction history and block data
- EVM-compatible (standard Solidity contracts)
- Maintained, versioned releases
