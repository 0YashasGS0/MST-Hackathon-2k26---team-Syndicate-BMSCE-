### 00:20 — SOW draft/merge/approve router + LLM merge agent
- **What:** Express Router for the SOW negotiation (`/drafts`, `/drafts/:id`, `/seller-input`, `/merge-sow`, `/approve-sow`, `/link`) with SQLite storage and an LLM merge agent. The LLM writes only `title`, `deliverables`, `exclusions` and `conflicts`. The server fills in buyer, seller, amount, deadline, review window and token (`USD_ADDRESS`). If the model tries to set any of those, the server value is kept and the attempt shows up in `conflicts`. Validation uses `parseSow()`, with one retry that includes the errors, then 422. Weights are never normalised. Every merge is a new version, and approvals reset. `proposeDealArgs` is derived only from the stored, re-hashed SOW, and a past deadline or wrong token blocks it. Party text sits inside `<data>` blocks, and `</data>` is escaped. Every LLM attempt is logged to `agent_calls` (the key is never stored).
- **Files:** `backend/package.json`, `backend/tsconfig.json`, `backend/src/sow/{router,store,index}.ts`, `backend/src/agent/{llm,mergeSow}.ts`, `backend/test/sow.test.ts`, `docs/API.md`
- **How to use (B1):**
  ```ts
  import { createSowRouter } from "./sow";          // backend/src/sow
  app.use(createSowRouter());                        // reads DB_PATH, LLM_API_KEY, LLM_MODEL, USD_ADDRESS, AGENT_DEMO_FALLBACK
  // or share your DB connection: app.use(createSowRouter({ store: new SowStore(db) }))
  ```
  The router parses JSON itself and returns errors as `{ error: { code, message, details? } }`. `shared` is a `file:../shared` dependency, so run `npm install` in `backend/`.
- **LLM notes:** Anthropic SDK with a single `submit_sow` tool. `tool_choice` forces that tool, except on models that reject forced tool use (Opus 5.5 / Fable 5.1), where it falls back to `auto` plus an instruction. `temperature: 0` is sent only to models that accept it. Current models (e.g. `claude-sonnet-5`) return a 400 on any sampling parameter, so determinism there comes from validation plus stored versions.
- **Tested:** `cd backend && npm test` → 10/10 (full flow and proposeDealArgs == stored SOW, stale version 409, re-merge resets approvals, 9000-bps weights → 2 calls → 422, LLM amount/deadline override flagged, stranger 403, past deadline 409, `<data>` escaping, auth 401/403, demo fallback). `npx tsc --noEmit` → 0 errors. Shared: 13/13. No network calls in the tests (mocked `LlmClient`).
